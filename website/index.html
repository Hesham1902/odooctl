The useful parts

Your local environments should feel like one tool.

01

Find the project first.

Register a folder once. odooctl remembers its services, ports, database, and custom addons path.

odooctl discover
02

Run the common actions.

Use the same short commands for up, down, logs, status, tests, shell access, and opening the browser.

odooctl status arc
03

Pull without the browser dance.

Fetch the newest Odoo.sh dump over SSH, restore it locally, reset admin access, and sanitize the copy.

odooctl pull arc -d dev
