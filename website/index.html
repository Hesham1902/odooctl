The useful parts

Your local environments should feel like one tool.

01

Find the project first.

Register a folder once. odooctl remembers its services, ports, database, and custom addons path.

odooctl discover
02

Run the common actions.

Use the same short commands for up, down, logs, status, tests, shell access, and opening the browser.

odooctl status demo-shop
03

Pull without the browser dance.

Fetch the newest Odoo.sh dump over SSH, restore it locally, reset admin access, and sanitize the copy.

odooctl pull demo-shop -d local

The desktop app

For the days when you do not want another terminal tab.

The desktop app gives you a project list and live Docker status. It uses the same registry and backend as the CLI, so the two views do not drift apart.

More than start and stop

The rest of the work belongs here too.

01

Project management

Discover Compose projects, keep a local registry, bootstrap a new environment, or remove one cleanly.

discover   projects   init   remove
02

Runtime control

See containers and databases, start or stop a stack, follow logs, open the browser, and restart on addon changes.

status   up   down   restart   logs   dev
03

Addon development

Use SQL or the Odoo shell, inspect installed addons, trace dependencies, compare databases, upgrade changes, and run isolated tests.

psql   shell   addons   deps   diff   upgrade   test
04

Database safety

Back up and restore databases, pull Odoo.sh snapshots, sanitize production copies, repair icons, and reset access safely.

backup   restore   pull   sanitize   reset   reset-admin
05

Storage and platforms

Understand Docker disk use, clean stale images and volumes, and work across macOS, Linux, and Windows with Docker Desktop.

space   gc   macOS app   Windows CLI
